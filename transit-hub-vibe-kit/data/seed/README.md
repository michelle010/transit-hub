# Development seed data

`cities_and_hubs.json` is a small, deterministic development fixture for 成都、乐山、南京、苏州.
Hub coordinates are approximate and rounded. Railway station codes are left unset until verified;
`FIXTURE_HUB` and `FIXTURE_RAIL` references are test identifiers, not identifiers from a real provider.
The records are marked `seed:test-fixture` and must not be used as production travel data.
